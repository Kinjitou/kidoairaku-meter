# 喜怒哀楽メーター

Webカメラの表情を、FACS（Facial Action Coding System）のアクションユニットの組み合わせに基づいて喜・怒・哀・楽それぞれ0〜100点で採点するWebアプリです。

- 顔解析：MediaPipe Face Landmarker（ブラウザ内で処理。映像はサーバーに送信されません）
- 公開URL：https://kinjitou.github.io/kidoairaku-meter/

## なりきりモード

- オリジナルのマスコット3種（もちねこ／おばけのフワ／ロボ太）が、口パク・まばたき・眉・喜怒哀楽に連動して動きます。
- 手元の写真をアップロードすると、顔の形に合わせて変形するお面になります（写真はブラウザ内でのみ使用し、保存・送信しません）。

採点式と根拠はページ下部「採点のしくみ」を参照してください。
